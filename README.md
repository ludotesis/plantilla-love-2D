# 🚀 Plantilla Love2D

> Una plantilla lista para usar con diferentes librerías preconfiguradas para iniciar rápidamente tu proyecto de desarrollo de videojuegos con Lua y LÖVE.

## 🌟 Ramas 

Este repositorio está organizado en diferentes ramas según las necesidades de tu proyecto. Cambia a la rama que mejor se adapte a tu juego:

<details>
  <summary><b>🌱 Rama Base</b> <i>(Clic para desplegar)</i></summary>
  
  <br>

  **[Ver código de la rama Base](https://github.com/ludotesis/plantilla-love-2D/tree/base)**
  
  La configuración inicial incluye las siguientes librerías esenciales:

  - **[Lume](https://github.com/rxi/lume):** Colección de utilidades súper prácticas para Lua.
  - **[Push](https://github.com/Ulydev/push):** Manejo de resolución virtual independiente de la pantalla (ideal para pixel art).
  - **[Anim8](https://github.com/kikito/anim8):** Sistema rápido y sencillo para la animación de sprites.
  - **[Bump.lua](https://github.com/kikito/bump.lua):** Detección de colisiones de cajas (AABB) optimizada para juegos 2D.

</details>

## 📋 Requisitos previos

Para utilizar esta plantilla necesitas tener instalado:
- [LÖVE Framework](https://love2d.org/)
- Un editor de código (como VS Code)
